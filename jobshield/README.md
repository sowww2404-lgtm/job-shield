# 🛡️ JobShield

### Check Before You Trust

JobShield is a web application designed to help users check job, internship, and course offers for potential fraud or suspicious activity before trusting them.

It analyzes the information provided by the user and gives guidance based on risk indicators, helping users make safer decisions about online opportunities.

## ✨ Features

- 🔍 **Check Offers** – Analyze a job, internship, or course offer for suspicious signs.
- 📊 **Dashboard** – View an overview of the checking results.
- 🕒 **History** – Keep track of previously checked offers.
- ⚖️ **Compare Offers** – Compare two offers to identify differences and potential risks.
- ⚠️ **Risk Assessment** – Highlights possible warning signs and provides a risk-based assessment.
- 💡 **Safety Guidance** – Helps users understand whether an offer requires further verification.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Detection:** Rule-based analysis and risk scoring
