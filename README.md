# JobShield

A fraud-detection web app that checks job offers, internship messages, links, and paid-course promotions for scam red flags before you trust or pay anyone.

🔗 **Live Demo:** https://sowww2404-lgtm.github.io/job-shield/
⚙️ **Backend API:** https://job-shield-uchm.onrender.com
📁 **Source Code:** [`/jobshield`](./jobshield)

> ⚠️ Hosted on free-tier services — the backend may take 30-50 seconds to wake up on first use after inactivity.

## What it does
- Paste or **upload** (.txt / .docx / .pdf) a job/internship offer, paid-course promotion, or link
- Get a 0–100 risk score with a Low / Medium / High rating
- See a plain-language explanation of every red flag detected
- Compare two offers side by side
- Built-in helper chatbot for quick scam-safety FAQs

## Tech stack
React (frontend) · Flask REST API (backend) · SQLite (history & dashboard stats)
